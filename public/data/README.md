# Template Base de Contrato

## ⚠️ ATENÇÃO

Para criar o arquivo `template_contrato_base.docx`, siga as instruções detalhadas em:

📄 **docs/CRIAR-TEMPLATE-BASE.md**

O arquivo deve ser colocado nesta pasta: `public/data/template_contrato_base.docx`

---

## Por que não está incluído?

Arquivos `.docx` são binários e precisam ser criados usando Microsoft Word ou LibreOffice Writer. 
Não é possível gerá-los automaticamente via código de forma simples.

## Como criar?

1. Abra o Microsoft Word ou LibreOffice Writer
2. Copie o conteúdo do arquivo `docs/CRIAR-TEMPLATE-BASE.md`
3. Cole no Word e formate adequadamente
4. Salve como `template_contrato_base.docx`
5. Coloque o arquivo nesta pasta

Alternativamente, você pode baixar um template pronto do sistema após a primeira configuração.
