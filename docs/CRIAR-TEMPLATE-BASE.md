# Template Base de Contrato - Instruções de Criação

## ⚠️ IMPORTANTE

Como não é possível criar arquivos .docx diretamente no código, você precisará criar este arquivo manualmente no Microsoft Word ou LibreOffice Writer.

## 📋 Instruções para Criar o Template Base

### 1. Crie um novo documento Word (.docx)

### 2. Copie e cole o conteúdo abaixo

### 3. Salve como: `template_contrato_base.docx`

### 4. Coloque o arquivo em: `public/data/template_contrato_base.docx`

---

## 🎨 Dicas de Formatação no Word

1. **Título Principal**: Use fonte maior (16pt) e negrito
2. **Subtítulos**: Use negrito e tamanho 12pt
3. **Texto normal**: Use fonte 11pt, estilo "Times New Roman"
4. **Marcadores**: Mantenha EXATAMENTE como estão: `{nomeAluno}`, `{cpfMae}`, etc.
5. **Espaçamento**: Use espaçamento entre parágrafos de 6pt
6. **Margens**: Configure margens de 2,5cm em todos os lados
7. **Alinhamento**: Use justificado para parágrafos longos

## ✅ Checklist Final

Antes de salvar o template, verifique:

- [ ] Arquivo está salvo como `.docx` (não `.doc`)
- [ ] Todos os marcadores estão entre chaves `{}`
- [ ] Nenhum marcador tem espaços extras: `{nome}` ✅ vs `{ nome }` ❌
- [ ] A formatação está aplicada fora das chaves
- [ ] O arquivo está em `public/data/template_contrato_base.docx`

## 🚀 Após Criar

4. Ajuste o template conforme necessário
